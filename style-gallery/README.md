# 超云 PPT · 全风格图鉴

这是 `chaoyun-ppt-design` 随附的本地风格图鉴，包含全部 207 种风格。页面采用大图、深色画廊与分类筛选形式。

## 打开

- 本地链接：在本目录执行 `python server.py --port 8880`，打开 http://127.0.0.1:8880/style-gallery/ 。仅监听本机地址。
- PowerShell 快捷启动：`pwsh -File ./start-gallery.ps1`。端口已占用时可传入 `-Port 8881`。

## 功能

- 207 种风格与 207 张完整原图，每页 24 种；默认按编号排序。
- 按编号、名称、视觉标签、用途、内容结构搜索；多个关键词以空格分隔，按同时匹配处理。
- 8 类主要使用场景、21 类视觉类别、5 档建议正文容量，支持组合筛选。
- 详情显示完整介绍、适用用途、内容结构、页面组织、素材形式、完整提示词与选型依据。
- 点击预览查看原始图片；详情支持左右切换、Esc 关闭、键盘方向键翻页。
- 收藏保存到当前浏览器的本地存储；换浏览器、清理浏览数据或更改打开地址不会迁移收藏。
- 复制风格提示词或 Codex 使用指令；剪贴板不可用时显示可手动复制的文本框。
- 深链接示例：`http://127.0.0.1:8880/style-gallery/#style=006`。
- 手机端单列画廊与纵向详情；宽屏使用多列布局。所有预览均来自本地，不依赖远程 CDN 或字体。

## 内容与边界

来源：`https://github.com/Lougle360/chaoyun-ppt-design`。页面从相邻的 `references/` 读取构建数据，复用 `assets/ppt-previews/` 的 207 张原图，并在本目录保留轻量缩略图。字段原样保留，名称以索引为准，不使用可能过时的图片文件名替代。图片是风格示例，不保证实际生成结果；场景、容量与内容结构标签是选择线索，具体判断依据可以在详情中展开查看。

页面负责介绍和选择风格；PPT 制作由已安装的 Skill 执行。此页面不调用付费服务、不自动更新飞书，也不上传收藏。

## 更新素材

只有重建素材时需要 Node.js，以及 Skill 内已安装的 sharp：

```powershell
node ./build-gallery.mjs
node ./verify-gallery.mjs
```

重建会更新 `thumbnails/` 和 `styles-data.js`；自定义网页代码和原图保持原样。
