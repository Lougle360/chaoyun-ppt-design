# 商业发布文案审核与付费生成门禁

本规则适用于对外发布、销售介绍、客户培训、品牌宣传等商业用途。此用途下，本文件优先于默认三节点把关、全自动模式和自动重试规则。用户更具体的指令优先。

## 1. 先完成可发布文案，不先花钱试错

在第一次付费生图前，保存并展示整套《发布版逐页文案.md》。每页逐字列出标题、正文、数字、单位、按钮名称、脚注和必要风险提示，用户应能直接判断成品会写什么。

大纲确认、风格选择、样张布局确认都不能替代发布文案确认。不得把“选106”“排版可以”等回答理解为认可未展示的整套文案。

同时单独保存《内部审核与待确认.md》，收录来源、矛盾、缺失截图、待核实字段和修改理由。内部记录不得作为生图可见文字输入。

## 2. 将内部说明与对外文字分开

- 默认禁止将“原文示例”“原文说明”“依据所提供文档整理”“待核对”“待确认”等审稿或制作话语放入发布页。用户明确要展示原文研究或引用语境的情况除外。
- 示例可以用于发布，但应写成面向观众的准确表达，例如“以1万元交易合作为例”。示例适用条件、金额单位和必要限定必须保留，不得变成普遍承诺。
- 不得为去掉审稿痕迹而删掉必要的风险提示、事实限定或对外引用。它们也应列入文案供确认，不自行堆加免责声明。
- 界面字段、价格、费用、权利义务等事实有冲突时，先向用户核实。不得自行猜测修正，也不得把疑问印在成品页上。
- 缺失实际截图时，先说明素材缺口和可用方案。不能伪造界面后声称是实际操作截图。

## 3. 付费前确认文案和范围

推荐顺序：免费大纲与全套发布文案 → 免费查看已有模板参考图 → 用户确认文案及风格 → 一张最终参数正文样张 → 用户确认样张及批量范围 → 生成其余页面 → 检查并交付。

调用前明确本次生成页数、模型或渠道、最终参数及预计费用。费用没有可靠依据时明确说无法确认，不编造金额。多方向比较优先使用已有模板预览，不默认生成多张付费候选。

付费门禁必须同时满足：

1. 全套发布文案已经展示并获用户确认。
2. 当前样张或批量范围已获授权。
3. 本次提示词可见文案与已确认版本一致，未掺入内部审核说明。

即使用户之前同意“全自动”或“继续生成”，也不能推定其认可后续擅自增加的对外文案；需要改文案时，先展示差异并取得确认。

## 4. 生成时防止扩大损失

一页生成后立即检查文字及事实再继续。出现擅自增字、事实错误、内部说明泄漏或明显版式偏离时，暂停后续付费调用，报告问题、已生成页数和可确认的费用信息。

失败页最多重试两次只是上限，不是自动花费授权。先提出具体修复方案与新增生成数量，获得当前修复授权后再调用。若用户已明确给出包含重试的预算及范围，在该范围内执行。

不确定被中断调用是否计费时，如实记录“计费状态未知”，不报作免费或已退款。

## 5. 交付前检查

逐页与《发布版逐页文案.md》核对，不仅检查文件存在。确认无内部审核话语、无擅自新增信息、无未解决的事实问题。没有完成以上检查的文件标为审核稿，不能声称可直接商业发布。

在《付费生成记录.md》中记录文案版本、用户确认节点、生成页码、样张和重试数量、输出路径、检查结果及实际可获得的费用信息。保留失败页和原稿，不覆盖用户批准的样张。
