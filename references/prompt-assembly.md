# 逐页提示词组装

> 商业发布用途优先执行 [发布文案审核与付费门禁](publication-copy-gate.md)：内部审稿记录与成品可见文字分开，全套发布文案先确认再生图。错误页暂停后续调用，重试需有明确授权。


## 提示词结构

每页提示词由以下部分组成：

```text
风格锁定
+ 页面任务
+ 准确文案
+ 构图要求
+ 输出要求
+ 禁止项
```

最终提示词写成自然、连贯的中文，不要堆成参数清单。

## 共用风格锁定

风格锁定必须取自 [中文风格目录](style-catalog.md)中选定风格的完整提示词，并结合已经确认的视觉规范。正式代表页通过后，继续引用 `style-master.png`，说明哪些特征必须保持、哪些具体内容不得复制。

示例：

```text
延续参考样张的暖白纸张质感、深绿色主色、少量朱红强调色、现代编辑插画语言、细线条和克制留白；保持相同的字体气质与视觉层级，但不要复制样张的具体内容、物件或构图。
```

不得从旧英文或日文案例库拼接风格提示词。

## 完整整页文生图提示词

这是默认模式。背景、图片、插画、图形、标题和正文必须直接生成在同一张 16:9 页面图片中。逐字列出允许出现的文字，并声明不能出现其他文字。

```text
生成一张16:9横版完整PPT成品页。{风格锁定}。本页要让观众理解：{页面任务}。画面只允许出现以下中文，不增字、不漏字、不改字：「{标题}」「{正文}」。{构图要求}。将背景、图片、插画、图形、标题和正文直接整合成同一张页面图片，图片垫底，禁止把图片与文字拆开。不要额外文字、伪字、水印、商标、无关人物或陌生品牌。
```

## 混合页提示词

只有整页文生图无法稳定生成准确长文字时，才生成无字底图或插画，再用原生 PowerPoint 文字叠加。

```text
生成一张16:9高信息密度PPT的无字视觉底图。{风格锁定}。本页观点是：{页面任务}。{构图要求}。为PowerPoint原生标题和正文保留{文字安全区}的干净区域，背景在该区域保持低对比度，不放置文字、数字、图标、人物面部或高频细节。不要出现任何汉字、字母、数字、水印、商标或装饰性伪字。
```

准确文案随后通过原生 PowerPoint 文本框加入。标题必须面向观众并直接表达结论。

## 原生数据页提示词

只有辅助视觉能明显提升理解时才调用 Image2。图表、表格、时间线、价格、日期、引文和精确数字必须使用原生 PowerPoint 对象。

数值必须准确或需要编辑时，不得把图表生成成图片。

## 构图要求

围绕本页叙事任务编写构图：

- 观点：一个强视觉锚点，加一块清晰证据区
- 流程：从左到右或从上到下推进，并预留标签位置
- 对比：两个均衡区域，只有一条明确对比轴
- 案例：具体场景加紧凑解释区
- 引语：一句主导文字配克制辅助图像
- 数据：一块图表区、一块解释区，减少装饰
- 行动：按优先级排列步骤，并显示终点

避免“做得好看一点”之类空泛要求，也不要连续堆砌形容词。

## 生成顺序

1. 选择一张有代表性的正文页用于公平比较风格。
2. 除非用户已给唯一参考或跳过把关，否则使用完全相同的内容分别生成 2—3 张候选样张。
3. 把关模式展示候选总览并获取选择；全自动模式自行评分、选择并记录，不暂停。
4. 一次性编写全部正式提示词，提前发现遗漏和重复构图。
5. 用选中风格和最终文案重新生成正式代表页。
6. 把关模式获取确认；全自动模式自行检查和修正。通过后保存为 `style-master.png`。
7. 附带正式代表页生成其余页面。
8. 提示词文件名与页面图片保持一致，例如 `03-key-claim.txt` 和 `03-key-claim.png`。

## 重试规则

失败页最多重试两次，每次只改变一项：

- 只修文字
- 只修裁切或主体位置
- 只修风格漂移
- 只删除多余物件

整页文字仍不准确时，停止重生并切换为混合页。保留已经通过的视觉部分，不要重做整套 PPT。
